# Inventory (Platzhalter)

Reserviert für die spätere Anbindung der Inventur an Business Central. Bewusst leer: Die Inventur-Anwendung ist außerhalb
des Scopes und wird nicht verändert. Neue BC-Funktionen für die Inventur entstehen hier nach demselben Muster wie
`MasterData/` und `Workforce/` (Port im Core, BC-Aufruf in `BcIntegration.Infrastructure/BusinessCentral`).
